RAG Query Rewrite · 策略路由与工作流实验室

把“策略勾选”升级为真正的路由实验：配置允许策略 → 查询理解 → Router 决策 → DAG 工作流执行 → 首轮检索评估 → 必要时二阶段补充检索。

先记住这个设计原则：前端勾选的是策略 Allowlist（允许使用的策略），不是“全部强制执行”。Router 根据 Query 特征、规则、模型建议和预算做最终决策；检索后还可以根据召回质量触发补充策略。

② 策略 Allowlist

关闭某策略表示 Router 不允许调用它；开启只代表“允许”，不代表一定执行。

生产建议：Allowlist、策略参数、触发规则、优先级、预算应分开配置。不要把所有策略开关等同于工作流步骤。
