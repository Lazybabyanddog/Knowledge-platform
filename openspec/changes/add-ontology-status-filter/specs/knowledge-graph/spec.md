# Spec Delta

## ADDED Requirements

### Requirement: 本体列表状态展示与筛选

系统 SHALL 在本体管理页的实体类列表与关系类型列表中，为每一行显式展示该定义的状态：`0` 显示为「有效」，`1` 显示为「失效」，两种状态均需与名称、编码同屏可见。

系统 SHALL 提供按状态筛选列表的能力，筛选项包含「全部」「有效」「失效」，默认值为「全部」。

系统 SHALL 让筛选只影响表格展示的行，不改变页面内数据的可用范围：父类名称解析、关系类型的起点类/终点类候选仍基于全量定义，已失效的实体类不会被移出候选。

列表所属页签 SHALL 以「当前可见条数/总条数」展示计数。

当筛选结果为空时，列表 SHALL 给出区别于「尚无定义」的空态提示。

#### Scenario: 列表展示状态列

- **WHEN** 管理员打开本体管理页，实体类列表中存在状态为 `0` 与 `1` 的定义
- **THEN** 状态为 `0` 的行显示「有效」标签，状态为 `1` 的行显示「失效」标签

#### Scenario: 默认展示全部状态

- **WHEN** 管理员首次进入本体管理页且未修改筛选
- **THEN** 筛选值为「全部」，两类列表都展示全部定义，页签计数为 `总数/总数`

#### Scenario: 按失效筛选

- **WHEN** 管理员把状态筛选切换为「失效」
- **THEN** 两个页签的表格都只展示状态为 `1` 的定义，页签计数变为 `失效数/总数`

#### Scenario: 按有效筛选

- **WHEN** 管理员把状态筛选切换为「有效」
- **THEN** 两个页签的表格都只展示状态为 `0` 的定义，页签计数变为 `有效数/总数`

#### Scenario: 切换页签保持筛选

- **WHEN** 管理员在实体类页签把筛选设为「失效」，随后切换到关系类型页签
- **THEN** 关系类型列表沿用「失效」筛选，不需要重新选择

#### Scenario: 筛选不影响关系候选

- **WHEN** 管理员筛选为「有效」，且某个实体类的状态为 `1`（失效）
- **THEN** 关系类型列表不展示该失效类，但关系类型弹窗的起点类/终点类候选中仍可选择它，父类列也能正确显示它的名称

#### Scenario: 筛选结果为空

- **WHEN** 管理员筛选为「失效」，且当前工作空间没有任何失效的实体类
- **THEN** 实体类表格显示「没有符合筛选条件的实体类」一类提示，而不是「还没有定义」的空态
