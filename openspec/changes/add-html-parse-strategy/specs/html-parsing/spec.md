# Spec Delta

## Purpose

让 HTML 文档按页面结构（标题、段落、列表、表格）转成可定位的内容块，供后续知识抽取使用；解析范围、标题判定与噪声剔除可通过解析策略调整。

## ADDED Requirements

### Requirement: HTML 文档的类型识别与策略路由

系统 SHALL 将扩展名为 `.html` 的上传文件识别为独立的 `html` 文档类型，不再归入纯文本类型。

系统 SHALL 在触发解析时按 `html` 类型选择解析策略：优先使用显式指定的策略，否则使用该类型的默认策略。

系统 SHALL 在 `html` 类型没有可用策略时返回 400，且不创建解析任务。

#### Scenario: 触发 HTML 文档解析

- **WHEN** 用户对一个已上传的 `.html` 文档触发解析且未指定策略
- **THEN** 系统使用 `html` 类型的默认策略创建解析任务
- **THEN** 任务统计中的引擎标识为 HTML 专用引擎，而非纯文本引擎

#### Scenario: 缺少 HTML 默认策略

- **WHEN** 触发解析时 `html` 类型没有任何默认策略，且未显式指定策略
- **THEN** 系统返回 400，提示需先配置解析策略
- **THEN** 系统不创建解析任务

#### Scenario: 不再走纯文本路径

- **WHEN** 一个 `.html` 文档被解析
- **THEN** 系统不调用纯文本引擎
- **THEN** 解析产物中没有包含 HTML 标签、属性或脚本代码的内容块

### Requirement: HTML 正文范围

系统 SHALL 支持通过策略配置 CSS 选择器限定正文容器；未配置时以整篇 `body` 作为解析范围。

系统 SHALL 在配置的正文选择器未匹配任何节点时回退到整篇 `body`，并在任务统计的告警中记录该情况。

系统 SHALL 在正文选择器无法解析为合法 CSS 选择器时判定解析失败，错误摘要中说明选择器非法，且不产生内容块。

系统 SHALL 默认排除 `script`、`style`、`noscript`、`template` 等非可见内容，其文本不得进入解析产物。

#### Scenario: 指定正文容器

- **WHEN** 策略配置正文选择器为页面中的正文节点
- **THEN** 仅该节点内的内容生成内容块
- **THEN** 该节点之外的导航、版权、脚本内容不出现在产物中

#### Scenario: 正文选择器未命中

- **WHEN** 策略配置的正文选择器在当前文档中匹配不到任何节点
- **THEN** 系统以整篇 `body` 解析
- **THEN** 任务统计的告警中包含"正文选择器未命中"的提示

#### Scenario: 非法正文选择器

- **WHEN** 策略配置的正文选择器不是合法的 CSS 选择器
- **THEN** 解析任务置为失败
- **THEN** 错误摘要指出选择器非法，且该任务没有内容块产物

### Requirement: 内容块类型映射

系统 SHALL 把 HTML 节点映射为已有的内容块类型，产物只使用系统既有的块类型集合。

系统 SHALL 按以下规则映射：

- 标题标签（`h1`–`h6`）映射为标题块，级别与标签层级一致
- 被标题选择器命中或类名包含 `title` 的节点映射为标题块
- 段落标签映射为段落块
- 列表项映射为列表块，每个列表项一个块
- 表格映射为表格块，保留行列结构，以便下游按表格处理
- 预格式化与代码标签映射为代码块
- 图片映射为图片块，仅在策略开启保留图片时生效，否则忽略
- 页眉、页脚、导航标签映射为页眉页脚块，并按策略中的去页眉页脚开关标记丢弃

系统 SHALL 保证块文本只包含可见文本：不含标签、属性、内联样式，连续空白折叠为单个空格，不换行符号替换为普通空格。

#### Scenario: 标题与层级

- **WHEN** HTML 中出现 `h1` 与 `h2` 标题
- **THEN** 产物生成对应的标题块，级别分别为 1 与 2
- **THEN** 标题块之间的正文块以该标题块为父块

#### Scenario: 表格块

- **WHEN** HTML 中出现一个 3 行 2 列的数据表格
- **THEN** 产物生成一个表格块
- **THEN** 表格块内容保留 3 行 × 2 列的行列结构

#### Scenario: 列表块

- **WHEN** HTML 中出现包含 3 个列表项的无序列表
- **THEN** 产物生成 3 个列表块，顺序与原文档一致

#### Scenario: 纯样式类标题

- **WHEN** 页面没有使用标题标签，而是用带 `title` 类名的段落作为标题（如法院公报案例页）
- **THEN** 这些节点被识别为标题块，而不是普通段落

#### Scenario: 脚本与样式不入产物

- **WHEN** 页面包含 `script`、`style` 与 `noscript` 内容
- **THEN** 产物中没有任何块包含这些节点的文本或代码

### Requirement: 多行标题合并

系统 SHALL 在策略开启标题合并（默认开启）时，把相邻的标题块合并为一个标题块，文本按原顺序以空格连接。

系统 SHALL 在策略关闭标题合并时，保留每个标题标签为独立标题块。

#### Scenario: 分行的长标题

- **WHEN** 页面把一个案例标题拆成 3 个相邻的标题节点
- **THEN** 产物只生成 1 个标题块，文本为三段按顺序拼接

#### Scenario: 关闭合并

- **WHEN** 策略关闭标题合并
- **THEN** 3 个相邻标题节点生成 3 个独立标题块

### Requirement: 无分页文档的定位语义

系统 SHALL 对 HTML 文档按单页处理：所有内容块的页码为 1，任务统计的页数为 1。

系统 SHALL 不为 HTML 内容块生成位置坐标。

系统 SHALL 在质量评分中按 1 页计算每页文本字符数。

#### Scenario: 页码与统计

- **WHEN** 一个 HTML 文档解析成功
- **THEN** 所有内容块的页码均为 1
- **THEN** 任务统计中的页数为 1
- **THEN** 内容块的位置坐标为未设置状态

### Requirement: 解析失败与质量降级

系统 SHALL 在 HTML 解析产出零个有效文本块时，把任务标记为低质量，而不是回退到纯文本引擎或视为成功且高质量。

系统 SHALL 在任务统计中保留 HTML 解析的告警信息（选择器未命中、无有效正文等），供任务详情展示。

系统 SHALL 不对 HTML 文档触发文字识别（OCR）分支。

#### Scenario: 正文为空

- **WHEN** 一个 HTML 文档除脚本与样式外没有可见文本
- **THEN** 解析任务成功但产出零个有效文本块
- **THEN** 质量评分低于阈值，任务被标记为低质量
- **THEN** 任务统计的告警包含正文为空的提示

#### Scenario: 不触发 OCR

- **WHEN** HTML 解析未发现有效正文，且策略开启了 OCR 相关开关
- **THEN** 系统不进入文字识别分支

### Requirement: HTML 编码兼容

系统 SHALL 支持 UTF-8（含 BOM）与 GB18030 编码的 HTML 文档解析。

系统 SHALL 在无法按上述编码解码时使用替换字符解码，并由质量评分把替换字符计入乱码比例。

#### Scenario: GB18030 页面

- **WHEN** 一个使用 GB18030 编码保存的 HTML 文档被解析
- **THEN** 中文正文正确解码，产物中不出现乱码替换字符

### Requirement: HTML 解析策略的可配置性

系统 SHALL 允许管理员创建、修改文档类型为 `html` 的解析策略，并将其设为该类型的默认策略。

系统 SHALL 支持以下 HTML 策略配置项：正文选择器、标题选择器、标题合并开关、额外噪声选择器列表、保留图片开关。

系统 SHALL 在接受策略时校验引用的解析引擎已注册，未注册时返回 400。

系统 SHALL 在 HTML 策略未配置上述可选项时使用默认值：正文范围为整篇 `body`、标题合并开启、不保留图片。

#### Scenario: 创建 HTML 策略

- **WHEN** 管理员创建文档类型为 `html`、引擎为 HTML 专用引擎的策略，并配置正文选择器
- **THEN** 策略保存成功并可用于解析任务
- **THEN** 策略详情返回所配置的正文选择器

#### Scenario: 默认值生效

- **WHEN** 管理员创建 HTML 策略时不配置任何可选项
- **THEN** 解析使用整篇 `body` 作为正文范围
- **THEN** 相邻标题被合并，且图片不进入产物

#### Scenario: 引用未注册引擎

- **WHEN** 管理员创建 HTML 策略时填写未注册的引擎标识
- **THEN** 系统返回 400，提示引擎未注册
- **THEN** 策略不被保存

### Requirement: 存量 HTML 文档可重解析

系统 SHALL 允许对已上传的 HTML 文档重新触发解析并使用新的 HTML 策略，无需重新上传文件。

#### Scenario: 重解析存量文档

- **WHEN** 一个在本次变更前上传的 HTML 文档被重新触发解析
- **THEN** 系统按 HTML 类型选择默认策略并生成结构化产物
- **THEN** 原有解析任务与其产物保持可查询
