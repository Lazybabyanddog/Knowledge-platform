# Spec Delta

## Purpose

为平台提供最小可用的身份认证与访问控制：用户凭账号密码登录，获得有期限的访问令牌，系统据此判定其角色与可执行的操作。

## ADDED Requirements

### Requirement: 账号密码登录

系统 SHALL 允许已启用的用户使用用户名和密码登录，并在校验通过后签发访问令牌与刷新令牌。

系统 SHALL 使用不可逆的哈希算法存储密码，任何接口都不得返回密码哈希。

系统 SHALL 在登录失败时返回统一的错误提示，不区分"用户不存在"与"密码错误"。

#### Scenario: 登录成功

- **WHEN** 用户提交正确的用户名与密码，且账号状态为启用
- **THEN** 系统返回访问令牌、刷新令牌与用户基本信息
- **THEN** 系统记录一条登录成功的审计日志

#### Scenario: 密码错误

- **WHEN** 用户提交正确的用户名与错误的密码
- **THEN** 系统返回 401 与统一提示"用户名或密码错误"
- **THEN** 系统记录一条登录失败的审计日志，包含来源 IP

#### Scenario: 账号被禁用

- **WHEN** 已禁用的用户提交正确的凭据
- **THEN** 系统返回 403，提示账号已被禁用

#### Scenario: 连续失败限制

- **WHEN** 同一用户名在 10 分钟内连续失败 5 次
- **THEN** 系统在该时间窗内拒绝该用户名的登录请求，返回 429
- **THEN** 系统提示剩余解锁时间

### Requirement: 令牌刷新与登出

系统 SHALL 允许使用未过期的刷新令牌换取新的访问令牌，且刷新令牌 SHALL 一次性使用。

系统 SHALL 支持用户主动登出，登出后该会话的刷新令牌立即失效。

#### Scenario: 刷新令牌

- **WHEN** 客户端提交有效的刷新令牌
- **THEN** 系统返回新的访问令牌与新的刷新令牌
- **THEN** 旧的刷新令牌立即失效

#### Scenario: 使用已失效的刷新令牌

- **WHEN** 客户端提交已使用过或已过期的刷新令牌
- **THEN** 系统返回 401，并要求重新登录

#### Scenario: 登出

- **WHEN** 已登录用户调用登出接口
- **THEN** 该会话的刷新令牌被标记为失效
- **THEN** 后续使用该令牌刷新将返回 401

### Requirement: 访问令牌校验

系统 SHALL 对所有受保护接口校验访问令牌的有效性、过期时间与签发对象。

系统 SHALL 在访问令牌缺失或非法时返回 401，在令牌有效但权限不足时返回 403。

#### Scenario: 未携带令牌

- **WHEN** 客户端访问受保护接口且未携带访问令牌
- **THEN** 系统返回 401

#### Scenario: 令牌已过期

- **WHEN** 客户端携带已过期的访问令牌访问受保护接口
- **THEN** 系统返回 401，响应体包含可识别的过期错误码，以便客户端触发刷新

### Requirement: 角色与权限

系统 SHALL 提供四种内置角色：管理员、贡献者、审批人、只读用户。

系统 SHALL 按角色限制接口的可访问范围，且权限判定在服务端完成。

| 能力 | 管理员 | 贡献者 | 审批人 | 只读 |
| --- | --- | --- | --- | --- |
| 用户与角色管理 | 是 | 否 | 否 | 否 |
| 上传与修改文档 | 是 | 是 | 否 | 否 |
| 配置解析策略 | 是 | 否 | 否 | 否 |
| 触发解析与重试 | 是 | 是 | 否 | 否 |
| 管理本体 | 是 | 否 | 否 | 否 |
| 确认/合并实体关系 | 是 | 是 | 否 | 否 |
| 提交审批 | 是 | 是 | 否 | 否 |
| 批准/驳回 | 是 | 否 | 是 | 否 |
| 只读查询 | 是 | 是 | 是 | 是 |

#### Scenario: 越权访问

- **WHEN** 只读用户调用上传文档接口
- **THEN** 系统返回 403，且不产生任何数据变更

#### Scenario: 审批人不能上传

- **WHEN** 审批人调用上传文档接口
- **THEN** 系统返回 403

### Requirement: 当前用户信息

系统 SHALL 提供接口返回当前登录用户的标识、显示名、角色列表与所属工作空间。

#### Scenario: 获取当前用户

- **WHEN** 已登录用户请求当前用户信息
- **THEN** 系统返回用户标识、显示名、角色列表与工作空间标识
- **THEN** 返回内容不包含密码哈希或令牌明文

### Requirement: 用户管理

系统 SHALL 允许管理员创建用户、修改用户的显示名与角色、启用或禁用用户、重置用户密码。

系统 SHALL 阻止管理员禁用或降级自己，避免平台失去唯一管理员。

#### Scenario: 创建用户

- **WHEN** 管理员提交新用户的用户名、初始密码与角色
- **THEN** 系统创建用户并返回其标识
- **THEN** 用户名重复时返回 409

#### Scenario: 禁用自己

- **WHEN** 管理员尝试禁用自己
- **THEN** 系统返回 400，提示不能操作自己的账号状态
